# Back2You – Lost and Found Platform

Back2You is a full-stack MERN application designed to help users report, search, and recover lost items efficiently within a community or campus environment.

## Features

- User authentication and login system
- Report lost and found items
- Upload item details and images
- Search and browse listed items
- Responsive user interface
- Secure backend API integration
- MongoDB database management

## Tech Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Installation

### Clone the repository
git clone <your-repo-link>
cd back2you

### Install frontend dependencies
cd client
npm install

### Install backend dependencies
cd ../server
npm install

### Run the Project
### Start backend server
npm start

### Start frontend
cd client
npm start
